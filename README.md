## 🚀 Главный кейс: proCEOss
**proCEOss** — это мобильное приложение для продуктивности, где пользователь получает прогресс за реальное выполнение задач и время фокусировки.

* **Разработка в соло:** от идеи, продуктовой логики и дизайна до написания текстов, сторлистинга и запуска.
* **Стек проекта:** Flutter + Unity (3D внутри приложения), Isar (локально) + Firestore (синхронизация), RevenueCat (монетизация и серверная проверка прав), FCM (уведомления), Codemagic (сборка для RU/EN локализаций).
* **Срок реализации:** ~3 месяца.
